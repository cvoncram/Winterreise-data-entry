🎵 Tools for _Winterreise_ Data Entry 🎼

These tools are designed to edit and fix CSV tables generated by Sonic Visualiser as well as helping to insert this data into MEI-XML files. They were created by Clemens von Cramon as part of the project Creating Schubert’s „Die Winterreise“ in Performance with Dietrich Fischer-Dieskau.

The process and calculations of mapping dynamic values onto beat markings and creating interpreted dynamics values is inspired by and closely resembles the Dyn-a-matic tool created by the Mazurka Project.

Select a tool here or in the navigation bar above:

  • Generate new MEI-XML files from metadata
  • Correct measure/beat markings and tempo (bpm) columns in CSV tables

Used frameworks, libraries, and packages

  • FastAPI for HTTP routing and services
  • Jinja2 for templating
  • pandas for data analysis and manipulation
  • NumPy for additional mathematical operations
  • lxml for processing XML in Python
