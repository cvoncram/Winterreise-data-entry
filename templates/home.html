Tools for Editing Sonic Visualiser Output

These tools are designed to edit and fix CSV tables generated by Sonic Visualiser as well as helping to insert this data into MEI-XML files.

Select any tool here or in the navigation bar above.

  • Generate new MEI-XML files from metadata
  • Correct measure/beat markings and tempo (bpm) columns in CSV tables
  • Map dynamic and timbral data from Sonic Visualiser onto measure/beat markings
  • Insert CSV values into MEI-XML files

This page and these tools were created by Clemens von Cramon as part of the project Creating Schubert’s „Die Winterreise“ in Performance with Dietrich Fischer-Dieskau.

Used frameworks, libraries, and packages

  • FastAPI for HTTP routing and services
  • Jinja2 for templating
  • pandas for data analysis and manipulation
  • NumPy for additional mathematical operations
  • lxml for processing XML in Python
