# Tools for Editing Sonic Visualiser Output

This application runs locally in your browser. It contains several tools to fix and edit CSV tables generated by Sonic Visualiser as well as helping to insert this data into MEI-XML files. It is also possible to generate new MEI-XML files from metadata.

---

## Features

- Generate new MEI-XML files from metadata
- Correct measure/beat markings and tempo (bpm) columns in CSV tables
- Map dynamic and timbral data from Sonic Visualiser onto measure/beat markings
- Insert CSV values into MEI-XML files

---

## Installation (Linux/macOS)

### Prerequisites

Python 3.12.3 and pip 24.0 or higher are required.

### Installation (in command line)

```bash
mkdir Winterreise_app #create a new folder in which to place the app folder
git clone git@github.com:cvoncram/Winterreise-data-entry-backend.git
python -m venv .venv #or python3, create virtual python environment 
source .venv/bin/activate #activate virtual environment
pip install -r Winterreise-data-entry-backend/requirements.txt #install additional requirements
deactivate #deactivate virtual environment
```
You will be able to start the application by clicking on the start_app.sh script.
